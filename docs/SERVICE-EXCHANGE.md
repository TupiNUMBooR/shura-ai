# Файловый обмен между сервисами

Каталог пользователя — `db/<messenger>/users/<user_id>/`. Пути ниже относительны к нему.

## `inbox/` — `ms-max` → `ms-openai`

- `<seq>.txt` — текст в UTF-8, пустой для сообщения только с вложениями. `<seq>` берётся из `message.body.seq` в MAX.
- `<seq>.<nn>.<ext>` — вложение с порядковым номером `<nn>`, например `112.01.jpg`. `ms-max` сохраняет JPEG, PNG, GIF, WebP, MP3, OGG, M4A и WAV в исходном виде.

`<seq>.txt` публикуется последним и служит сигналом готовности. При неподдерживаемом MIME-типе приём завершается с ошибкой до публикации текста и обновления маркера MAX.

## `outbox/` — отправка в чат

`ms-openai` пишет ответы, расшифровки и сигналы чата. `ms-yookassa` пишет ссылки и подтверждения оплаты. `ms-max` формирует меню `/buy` и отправляет всю очередь.

| Файл | Действие |
| --- | --- |
| `seen`, `seen_<id>` | Отметить чат прочитанным (пустой файл). |
| `typing` | Показать индикатор набора (пустой файл). |
| `*.txt` | Отправить текст в UTF-8. |
| `message_<id>.json` | Отправить текст с необязательными кнопками. |

В `message_<id>.json` каждый вложенный массив `buttons` задаёт ряд. Кнопка `callback` передаёт боту `payload`, кнопка `link` открывает HTTPS-адрес `url`. `ms-max` преобразует ряды во вложение `inline_keyboard`.

```json
{
  "text": "Выбери пакет кредитов",
  "buttons": [
    [{"type": "callback", "text": "5000 кредитов · 79 ₽", "payload": "buy:5000"}],
    [{"type": "link", "text": "Условия оплаты", "url": "https://example.org/terms"}]
  ]
}
```

Меню пакетов — `message_buy_<seq>.json`. Ссылка на оплату приходит отдельно в `message_payment_<id>.json`.

MAX проверяет обычные файлы непосредственно в `users/*/outbox/`, пропуская имена на `.`. При пустой очереди ждёт 250 мс. Приоритет общий для всех пользователей — `seen` → `typing` → `*.txt` → `message_*.json`. При равном приоритете выбирается первый полный путь по сортировке `LC_ALL=C`. ID чата берётся из `max_chat_id.txt` в каталоге пользователя.

Отправленные сообщения удаляются. Неизвестный тип файла, ошибка формата или отправки дают `WARN`. Файл либо его недоставленный остаток перемещается в соседний `outbox-failed/`.

## `payments/orders/` — `ms-max` → `ms-yookassa`

Кнопка `buy:<credits>` создаёт `<credits>.json` с количеством кредитов и HTTPS-адресом из `MAX_PAYMENT_RETURN_URL`. Повторное нажатие сохраняет заказ, уже стоящий в очереди.

```json
{"credits":5000,"return_url":"https://web.max.ru/829005994"}
```

`ms-yookassa` берёт цену из своего каталога и передаёт адрес в `confirmation.return_url`. При повторной попытке использует прежние адрес и `idempotence_key`. Ссылка на оплату попадает в `outbox/`, запись платежа — в `payments/processing/<payment_id>.json`, затем в `payments/completed/` или `payments/failed/`.

## Файлы баланса

- `credits_received.txt` — получено. `ms-max` задаёт стартовое значение, `ms-yookassa` начисляет кредиты после оплаты.
- `credits_spent.txt` — потрачено. `ms-openai` списывает кредиты после обработки запроса.

Файлы содержат неотрицательные целые числа. Баланс — `credits_received − credits_spent`. Отсутствующий файл считается нулём.
